# Ввод новой схемы в прод — чек-лист

> Ветка `feature/kiosk-catalog-redesign`. Всё уже работает на встроенном
> фолбэке — этот чек-лист про то, как перевести генератор на живую таблицу.

## Что изменилось (кратко)

- **Kiosk PRO**: 28 карточек-вариантов → 12 карточек семейств + селектор
  комплектации (процессор/сканер) + опции, разбитые по обязательности
  (в комплекте / обязательная / доп) + фискалка по паттерну семейства.
- **Наименования**: клиенту в КП уходит обезличенное имя из «Правил семейств»
  (без POScenter / Sam4s / МС / Атол). Менеджер видит внутреннее имя.
- **Планшетный Kiosk**: цена планшета берётся из живого каталога (конец дрейфу
  Redmi 33k/31k). Замена планшета в превью снова работает.
- **Гард**: «Рассчитать» заблокирована для Kiosk PRO без выбранной модели
  (конец случайному POScenter Atlas в КП).
- **Без хардкода и догадок**: категория/крепление/фискалка больше не угадываются
  по подстрокам — всё задано в таблице явно.

## Как это устроено в переходный период

Код читает вкладки **«Номенклатура (киоски)»** и **«Правила семейств»**.
Пока их нет — работает **встроенный фолбэк** (`src/lib/catalog-fallback.ts`,
снимок на 08.07.2026). Поэтому:
- **ничего не ломается** до переключения таблицы;
- как только добавишь вкладки — живые данные автоматически перекроют фолбэк.

## Шаги ввода (10 минут)

1. Открой рабочую Google-таблицу
   (`1GGIOWoQmk7yLZjWSeY0wpFiKgrrYZ62TV2numdL7qXc`).
2. Создай вкладку **«Номенклатура (киоски)»**, импортни в неё
   [`nomenclature_kiosks.csv`](nomenclature_kiosks.csv)
   (Файл → Импорт → Загрузить → «Вставить на новый лист» / заменить данные листа).
3. Создай вкладку **«Правила семейств»**, импортни
   [`families.csv`](families.csv).
4. Старую вкладку **«Киоски»** можно оставить (код её игнорирует) или удалить.
5. Вкладки **Планшеты / Кронштейны / Периферия** — не трогай, они работают как
   раньше. *(Опционально: добавь в них колонку «Имя для КП» с обезличенными
   именами — тогда бренд планшета не утечёт при замене в превью. Сейчас имя
   подбирается по встроенной карте, для Honor/Poco падает на «Планшет Android».)*
6. Открой генератор → «Обновить каталог из Google Sheets» → выбери Kiosk PRO.
   Должны появиться 12 карточек семейств с ценами из твоей таблицы.

## Что проверить (сверка A1–A6, см. SPEC.md §8)

- **A1 — K320**: `Фиск. паттерн = встроенный` → в КП строка «ККТ Ритейл
  Комбо-01Ф (в составе киоска)» 0 ₽ + «Фискальный накопитель ФН 15». Комбо
  заменяет и принтер, и казначей (уточнено 08.07).
- **A1b — МС 24 / МС 32 (открыто)**: сейчас у них принтер 80 + Атол (казначей)
  + ФН. Если правильно тоже «Комбо + ФН» — добавь в таблицу строку-фискал
  «ККТ Ритейл Комбо-01Ф» с ценой и поставь этим семействам `Фиск. паттерн =
  встроенный` (или скажи цену — поправлю).
- **A2** — сканер МС Mini/21 как ось комплектации (заводской).
- **A5** — дефолт-процессор = самый дешёвый (колонка «Процессор по умолчанию»).
- **A6** — L-240/L-320: крепление настенное «в комплекте», напольное/настольное
  опциями (в описании было «только напольное и настенное» — сверь).

Любую из этих правок делаешь **в таблице**, не в коде.
